# Job Tracker — Backend

Backend for an AI-powered job application tracker. Built with Java, Spring Boot, and PostgreSQL, with JWT-based authentication and Google Gemini integration for resume analysis.

It handles user authentication, full CRUD for job applications, resume upload and text extraction, AI-powered matching between a resume and a job description, and AI-generated interview question suggestions based on identified skill gaps.

**Frontend repo:** [jobtracker-frontend](https://github.com/VedantAdka/jobtracker-frontend)

## Tech stack
Java 17, Spring Boot, Spring Security, PostgreSQL, JWT, Apache PDFBox, Google Gemini API, Docker
